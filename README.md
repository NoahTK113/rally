# Rally

A 2D physics paddle game. Hit it over the net, put it in the goal.

Play: open the page, one player hosts and shares the 4-character room code, the other joins.
Connection is peer-to-peer over WebRTC - no server.

Controls: mouse to move, wheel or A/D to rotate, hold right-click for fine rotation,
S to level, F to serve, R to reset the score, H for the tuning panel.
